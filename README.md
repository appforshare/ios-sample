# AppForShare iOS sample

A minimal SwiftUI app used to test [AppForShare](https://appforshare.io) builds on GitHub Actions
([guide](https://appforshare.io/docs/github-builds)). The Xcode project is generated with
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`:

```sh
brew install xcodegen
xcodegen generate
```
